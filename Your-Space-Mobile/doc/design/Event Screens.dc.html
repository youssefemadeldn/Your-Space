Events, guests & reciprocity — new screens Built on the confirmed contract: EventProfileDto exposes Name / EventDate? / TotalGuestCount only (no status breakdown on the list). EventGuestProgressSummaryDto adds Not-invited / Invited / Skipped totals plus a per-group GroupGuestProgressDto (TotalPersonsInGroup / GuestsAddedCount / status counts) — including groups with zero guests added. EventGuest status transitions have no state-machine guard, so every action (mark invited, skip, revert, remove) is always available. BulkAddGuestsResultDto backs the add-guests confirmation. Reciprocity suggestions reuse the People list's PersonProfileDto shape. Same Button, Input, Select, Switch, Chip, Badge, ListTile, Snackbar and logo lockup as the earlier batch — nothing restyled. The invite-method chip picker is the same one used on the Occasion History sheet, reused as-is for marking a guest invited. Tweaks: language (English / العربية — mirrors every screen) · group filter as chips or dropdown. Event names flip with the language (Event carries NameAr, like Group); person names never do. Copy stays gender-neutral and passive ("the invite was sent", not "he/she was invited"); names, phone numbers and dates stay LTR-isolated inside Arabic layouts.
