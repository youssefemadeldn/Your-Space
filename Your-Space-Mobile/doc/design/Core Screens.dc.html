Groups, People & reciprocity — core screens Built on the confirmed backend contract: Groups expose Name only, People expose Name / PhoneNumber / GroupName / HasReciprocityHistory, occasion history exposes InvitedMe, InviteMethod (WhatsApp · PhoneCall · Physical), OccasionName, OccasionDate and Notes. Same Button, Input, Select, Switch, ListTile, Badge and logo lockup as the auth flow — nothing restyled. Create and edit reuse one form each: same fields, same validation, same layout — only the sheet/AppBar title and the CTA change ("Create group" → "Save changes", "Save person" → "Save changes"), and edit arrives pre-filled. That matches the contract, where UpdateGroupDto / UpdatePersonDto treat a null field as "leave unchanged". Tweaks: language (English / العربية — mirrors every screen; occasion copy is gender-neutral passive, so no Gender field is needed on Person) · reciprocity indicators on/off · group filter as chips or dropdown · phone numbers in People rows. Group names flip with the language because Group carries NameAr; person names never do — Person has no NameAr field, so a contact's name renders exactly as it was entered.
